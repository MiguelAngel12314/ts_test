# CSV

Descripción
- This program permit upload CSV File and show in a table

Requisitos
- Node.js (v14+ recomendado)
- npm

Installation
1. Clone Repository.
```
git clone repository
```
2. Open repository 
```
cd ts_test
```
3. Install dependencies 
```
npm install
```

Run project

- Iniciar la aplicación (si existe script):
```
npm start
```

Basic Structure
- node_modules/ — dependencies (excluded for .gitignore)
- package-lock.json — dependencies block (excluded for .gitignore)
- src/ — source code
- package.json — cointain all dependencies to the project
- snowpack - Its a dependency for development without compile in frontEnd
